# noaa-gfs-analysis-virtual validation — questions for Alden

Seven, ordered by consequence. Each has the evidence line that raises it and a
recommendation. Items 1-3 change stored values or which source message a chunk
references, so under the step-5 gate they block the analysis full backfill's
affected positions; 4-7 do not.

1. **sunshine_duration_surface serves lead 0 at 00/06/12/18 UTC, so the series drops
   18,000 s -> 10,800 s every sixth hour and never reaches the 21,600 s its comment
   claims.** Evidence: 24 random synoptic positions all exactly 10,800 s; 24 random
   hour-5 positions all exactly 18,000 s; largest value across all 48 is 18,000 s. The
   store's 12:00 field is bit-identical to `gfs.t12z...f000 SUNSD:surface:anl`.
   Recommendation: select leads 1-6 for the analysis, scoped to the analysis product —
   NOT via `hour_0=False` in the shared catalog, which would assert falsely that the
   source has no f000 record and would suppress it for the forecast product.
   Changes stored values at 1 in 6 positions. **Decision needed: approve the value change?**

2. **Five instantaneous variables take the previous cycle at synoptic hours, so
   instantaneous convective precipitation exceeds the total precipitation rate.**
   Evidence: 8.8-9.9% of cells at exactly 00/06/12/18 UTC and 0 cells at all twenty
   other hours; 11.6k-13.9k cells where convective is positive and total is exactly zero.
   Affects instantaneous_precipitation_convective_surface,
   potential_evaporation_rate_surface, pressure_convective_cloud_bottom/top,
   convective_cloud_cover.
   This is the analysis contract choosing maximum valid-time coverage over same-cycle
   cross-variable coherence. **Decision needed: which does the analysis promise?** If
   coherence, it is a lead-selection change and blocks like item 1.

3. **total_ozone_atmosphere uses units="DU" with no standard_name.** CF defines
   `equivalent_thickness_at_stp_of_atmosphere_ozone_content` for this quantity and DU is
   non-SI. Recommendation: adopt the standard name AND a CF-recognisable length unit
   numerically equivalent to DU, rather than the name atop an unrecognised unit.
   Changes values. **Decision needed: approve?**

4. **The gravity-wave surface stresses carry CF standard names asserting a direction, but
   the convention is unverified.** Evidence: uncorrelated with the 10 m wind (r = +0.05,
   +0.06), so it cannot be settled from the data. Their siblings
   momentum_flux_u/v_component_surface needed an explicit sign comment.
   **Decision needed: are `atmosphere_eastward_stress_due_to_gravity_wave_drag` and its
   northward counterpart justified for U-GWD/V-GWD?** Needs the NCEP definition, not a guess.

5. **The stale-index guard discards an entire source file on one bad message and only
   warns.** Evidence: 12 files on 2022-11-29/30 carry sidecars stale against their objects;
   10 tripped the guard, and 3 drifted but stayed in bounds so misaligned references were
   written that exist but do not decode. Blast radius 9 positions, not 7. The published
   materialized `noaa-gfs-analysis` carries the same holes. Same guard in the three HRRR
   virtuals; ECMWF AIFS-single has a narrower copy that checks only matched messages.
   Recommendation: validate the index against the object (read 16 bytes at offset 0,
   unpack GRIB section-0 length, compare against `starts[1]-starts[0]` — caught 12 of 12
   with zero false positives across 1,003 files), raise the log level to error, keep the
   whole-file discard. Per-message skip is strictly worse. **Decision needed: approve the
   guard change?** The 7+2 positions cannot be recovered by a re-run until it lands.

6. **CheckVirtualManifestCompleteness cannot see a written-but-undecodable reference.**
   Evidence: it probes reference existence with no decode, by its own docstring, so the
   three poisoned positions passed it. **Decision needed: should it decode a sample?**

7. **Deep-soil liquid moisture loses a decimal place at 2022-02-28T18:00 and the archive
   carries it faithfully.** Evidence: independent GRIB metadata shows decimal scale 1e-3
   -> 1e-2 and 12 -> 9 bits; message shrinks 357,630 -> 263,684 bytes while its SOILW
   companion is unchanged. Consequence: liquid exceeds total at 20-57% of land cells, so
   total minus liquid yields negatives until 2022-07-03. No code change proposed — this is
   a review note. **Confirming only: report it and carry the source values unrepaired?**
