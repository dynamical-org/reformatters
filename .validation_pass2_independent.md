# Independent review of validation pass 2

I reviewed only `pass2_raw_only.md` and the expressly permitted implementation and policy files. I did not open any of the prohibited review/conclusion files.

## Headline judgment

The report contains three publishable user-facing findings: the deep-soil precision break (A1), the permanent-ice soil-moisture mask (A2), and a corrected, more cautious description of potential-vorticity-surface availability (A6). A3, A5, and A7 justify metadata comment fixes. A8 is not established well enough to encode as fact. A4 and A9 turn ordinary or negligible source behavior into findings, and should be cut. A10 is correctly no action.

## Calls on A1–A10

### A1 — real defect

This is a real upstream data-quality defect, not evidence of a bad archive transformation. The observed transition is exceptionally sharp: one array changes from roughly 0.001 to 0.01 value spacing at 2022-02-28T18:00, its total-moisture counterpart does not, the inequality violations begin at the same instant, and directly fetched source messages show the same before/after encoding-size and decoded-grid change.

The evidence is sufficient to attribute the **packing/encoding transition to the upstream bytes**. It is not fully sufficient for the stronger phrase “carried faithfully”: the source-file check used gribberish, the same decoder used on archive reads, so it is not an independent validation of decoding. The 26% message-size reduction makes a decoder-only explanation unlikely, but an ecCodes/rasterio comparison or direct inspection of GRIB packing metadata would close that last gap. Nor does the evidence show that NCEP intended the change. Say “the source GRIB encoding changed,” not “NCEP deliberately changed the precision.”

The report also overstates “two decimal places.” A decoded grid with approximately 0.01 spacing is quantization, not necessarily decimal rounding, and later maxima such as 1.00408 demonstrate that “two decimal places” is not literally stable across files. The user-facing note should say the quantization spacing coarsened by about a factor of ten.

Changing stored values to repair total-minus-liquid would be a separate owner decision. The validated action is to retain source values and disclose the time-bounded defect.

### A2 — comment fix

The eight variables need stronger comments, and this finding also qualifies for the narrow user-facing masking exception. These are intrinsic permanent-land-ice placeholders spanning a range rather than one normalizable fill value; users must mask them. “Values are near 1 over permanent land ice” is incomplete because it neither says they are not soil-moisture measurements nor gives the required mask.

The proposed `>= 0.9` threshold is supported by a physical cross-check, not merely by the value histogram: the cells align with soil type 16, zero vegetation, and invariant field-capacity/wilting-point values, while the ice cells stay at roughly 0.959–1.0. That is the right kind of evidence under AGENTS.md. The threshold came from the observed gap at three sampled times, with the roughly 1,240 nominally non-type-16 cells above 0.9 inferred to be interpolated ice-margin cells. It did **not** come from an authoritative source definition or an exhaustive all-8,760-hour scan.

Accordingly, the mask instruction is justified for the validated window, but these report claims overreach: “equivalent to soil type rounding to 16,” “neither clips real data,” and “no real soil cell anywhere in the archive reaches 0.9.” The displayed counts actually show that the equivalence is not exact, and the archive-wide claim is broader than the three-time threshold test. Use the moisture threshold directly; do not tell users it is exactly interchangeable with a rounded soil-type mask.

The shared comments should identify the values as permanent-land-ice placeholders and end with `Mask values >= 0.9.` The same evidence should be checked before propagating that wording to any product not covered by this validation.

### A3 — comment fix

This is not a wrong-reference defect. The analysis integration's explicit contract is “shortest lead at which each variable is published.” At synoptic hours, an hour-0 variable can use the new cycle's lead 0, while a variable absent at hour 0 must use the preceding cycle's lead 6 to represent the same valid time. The implementation does exactly that. Pointing the five variables at the new cycle would point at messages that the catalog says do not exist; substituting NaN would discard the shortest available valid-time estimate.

The report is right that this is intrinsic and belongs in comments, not in a validation review note. Each affected variable should say that at 00/06/12/18 UTC it comes from the preceding cycle's 6-hour forecast because it has no lead-0 source value. That is especially important for `instantaneous_precipitation_convective_surface`, because cross-variable inequalities against lead-0 fields need not hold at those four hours.

The evidence directly establishes selection behavior and the one-day precipitation inconsistency. It does not independently inspect source indexes to prove the asserted reason that all five records are absent from every f000 file; that reason is inherited from `hour_0=False` and the integration contract. This is enough for a code/comment decision, but the report should not present its one-day comparison as an archive-wide measurement of exceedance frequency or magnitude.

### A4 — nothing

Cut this finding. Its title says deep land-surface state “updates only four times a day,” but its own numbers show nonzero changes at other hours. What was measured is that cycle-boundary steps dominate total variation at three land points during three 15-day windows. That is expected in an hourly analysis assembled from leads 0–5 of successive forecast cycles: slowly evolving deep state changes little within a cycle and is reanalysed at the next cycle.

The report generalizes from 45 days at three points to global variables, calls a dominance ratio an update frequency, and treats ordinary cycle stitching as a dataset characteristic requiring action. At most, the evidence supports “larger changes often occur at cycle boundaries at the sampled points.” That is not a defect, mask, unavailable-data pattern, or source-era change. A3's provenance comments explain the only unusual source-selection semantics users need.

### A5 — comment fix, narrowly

Most of A5 is normal source precision and should not become metadata or user-facing prose. The actionable exception is `ventilation_rate_planetary_boundary_layer`: if source precision is sometimes 1,000 m2 s-1, a decoded zero can mean a small positive value rounded down. That is an intrinsic and non-obvious interpretation users may rely on, so it merits a concise variable comment.

The report overreaches in saying all listed grids are GRIB packing precision and “none of it is ours.” It measured decoded value spacing, not packing headers, and did not compare through an independent decoder. Field-dependent unique-value gaps are not by themselves proof of the precise encoding mechanism. The virtual architecture makes an added archive-side rounding step unlikely, but it does not rule out codec behavior. This limitation does not erase the observed quantization; it limits the causal wording.

Do not add comments for every listed variable. The vertical-shear steps are under 1% of range and visually immaterial; several other grids are ordinary resolution for their quantities. The ventilation-rate zero semantics are the one clear reader-facing consequence.

### A6 — real defect in the prior report, not in the data

The correction's core is sound: “a broad equatorial band” is contradicted by the shown latitude statistics. The deep tropics are mostly present, while missingness is concentrated mainly in the opposite hemisphere's extratropics for positive versus negative PVU surfaces.

The replacement wording is itself too broad. “Each is absent over the opposite hemisphere,” “93–100% absent south of 30S,” and “complete north of 10N” do not hold uniformly even in the table: positive 0.5-PVU temperature is only 74.5% missing at 30–60S in one snapshot and has 14.6% missing at 60–90N; negative 0.5-PVU also has missing cells in the Southern Hemisphere. The report shows detailed latitude numbers for only the 0.5- and 2-PVU surfaces. Identical NaN masks across quantities lets those surfaces generalize from temperature to the six quantities, but does not by itself establish the intermediate 1- and 1.5-PVU geography.

Replace the old statement with a qualitative summary: positive-PVU variables are missing predominantly in Southern Hemisphere extratropics and negative-PVU variables predominantly in Northern Hemisphere extratropics; the tropics are largely present, and polar availability varies with PVU surface, season, and whether that surface exists in the atmospheric column. Avoid fixed percentages or “complete” unless all eight surfaces are tabulated across the window.

### A7 — comment fix

The measured magnitude is strong evidence that the old 280–315 nm parenthetical does not describe the archived diagnostic. Source fidelity does not make incorrect metadata acceptable. Remove the unsupported band immediately if an authoritative replacement is not yet available.

The report does not establish the correct band. Its physical estimate is a plausibility argument, and it explicitly did not consult the NCEP/RRTMG definition. Therefore “consistent with NCEP's broader RRTMG band” is a hypothesis, not a finding. An exact replacement wavelength range must be backed by the authoritative diagnostic definition; until then, use a band-unspecific comment rather than substituting another number.

### A8 — owner question

The observed same-sign hemispheric means are real. The claimed cause — a globally right-moving storm-motion solution — is not established. Positive means in both hemispheres do not uniquely identify the storm-motion algorithm or its sign convention, and no source definition or independent archive was checked.

The owner should decide after consulting an authoritative NCEP/SPC definition or source implementation. A comment may then document the actual convention. Do not encode “globally right-moving” based only on these two maps and monthly global means. This does not belong in the three user-facing validation categories regardless.

### A9 — nothing

Cut this as a dataset finding. The report establishes trace positive decoded values at some high levels and shows that the default 300-hPa plot is uninformative for several hydrometeors. It does not establish the asserted GRIB packing-reference mechanism: exact zeros at lower levels do not rule out packing-parameter-dependent decoder behavior, and no raw-message/header or independent-decoder comparison was made.

The trace amounts are many orders below meteorological significance and need neither masking nor a user warning. The useful conclusion is procedural: the validation is incomplete for vertical groups and should rerender hydrometeors at representative lower-tropospheric levels. That is a validation-coverage gap, not archive metadata.

### A10 — nothing

No action. The suspected caps/floors lack pileups, the cloud-cover name is an established cross-dataset convention, the remaining items are already explained by A1/A4/A5/A9, and the long-name/short-name differences are harmless source-name fidelity rather than a semantic error. Do not turn consistency nits into metadata churn.

## Where the report overreaches

The important overclaims, collected in one place, are:

- A1 proves an upstream encoding transition, but not NCEP intent or fully independent decode fidelity; “two decimal places” is technically inaccurate.
- A2's threshold is physically well supported but sampled, not exhaustively proven clean at every hour, and it is not exactly equivalent to rounded soil type 16.
- A3's message selection is established; source absence is represented by configuration rather than independently rechecked, and the precipitation exceedance was measured for one day.
- A4 turns cycle-boundary-dominated variation at three points into “updates only four times a day,” contradicting its own non-synoptic variation.
- A5 assigns a GRIB-header mechanism without reading the headers or using an independent decoder.
- A6 correctly rejects an equatorial missing band, then replaces it with absolutes and percentages that do not hold across even the displayed 0.5-PVU table, much less all eight surfaces.
- A7 disproves the old band description but does not establish the correct wavelength interval.
- A8 infers a storm-motion algorithm from hemispheric sign statistics; that cause is not identified by the measurement.
- A9 infers a packing-reference mechanism without raw/header evidence and elevates negligible trace values into a data finding.
- The global “all 272 arrays passed” tone is stronger than a review that plotted only one of 57 or one of 8 vertical levels can support.

## Effect of the eight not-completed items

### Materially weaken a conclusion

1. **One vertical level per group.** This materially weakens the overall no-defect conclusion for all 19 grouped variables. A9 itself demonstrates why: the chosen 300-hPa level can be nearly empty and therefore cannot validate lower-tropospheric hydrometeor structure. Representative low, middle, and high levels are needed; not all 57 levels, but more than one.

3. **No broad element-wise source comparison.** This does not weaken A1's observation, but it weakens blanket fidelity language, especially A5's “none of this is ours.” A virtual store removes a rewrite stage; it does not independently validate index selection or codec interpretation.

4. **A5 packing headers not inspected.** This directly weakens the claimed GRIB packing mechanism. The coarse decoded grids remain observed facts; their precise cause does not.

5. **A7 source definition unresolved.** This directly prevents an exact replacement wavelength range. It does not prevent deleting the contradicted 280–315 nm claim.

6. **A8 convention not independently defined.** This directly defeats the causal conclusion. Same-sign means do not prove a globally right-moving algorithm.

8. **Extreme six-hour precipitation not source-checked.** This weakens the broad “physical ranges passed” conclusion. A 229–375 kg m-2 six-hour maximum is consequential enough that plausibility and one smaller previously noted event are not a substitute for checking the largest source message.

### Cosmetic or non-consequential to the stated conclusions

2. **Availability/decode health not rerun in pass 2.** In a deliberately cumulative second pass, relying on the first pass's exhaustive scans is acceptable, and the 3,808 successful whole-field decodes corroborate it. This would be a substantive omission only if pass 2 were presented as a standalone validation.

7. **Nine wind-v temporal plots use different points/windows.** This prevents direct point-for-point ladder comparison for those nine panels, but the report used the sampled full-period series and both spatial maps instead. It does not weaken A1–A10 or the main geometry/range conclusions.

## User-facing findings

### Patterns of unavailable data

- **Potential-vorticity-surface variables are unavailable mainly in the opposite hemisphere's extratropics.** Positive-PVU variables are predominantly unavailable in Southern Hemisphere extratropics, and negative-PVU variables predominantly in Northern Hemisphere extratropics. The tropics are largely present; polar availability varies by PVU surface and season where the requested surface does not exist in the atmospheric column.

### Variables the user must explicitly mask

- **Mask values greater than or equal to 0.9 in all eight soil-moisture variables.** Values in this range represent permanent land ice rather than soil moisture in the four `volumetric_soil_moisture_*` and four `liquid_volumetric_soil_moisture_*` variables.

### Source data changes over time

- **`liquid_volumetric_soil_moisture_100_200cm` has coarser source quantization from 2022-02-28T18:00 UTC through the end of the validated window.** Its value spacing changes from approximately 0.001 to approximately 0.01, causing it to exceed `volumetric_soil_moisture_100_200cm` at some cells by up to about 0.010. Derived frozen-water values computed as total minus liquid can therefore be slightly negative during this period.
